# Approved artwork

Only artwork the creator has approved for use in the army book. Anything still being
iterated on belongs outside this folder.

Name files by format and subject, lowercase kebab-case, following the editorial spec:

    spread-wild-hunt-barrows.webp
    page-robin-fair-portrait.webp
    half-h-fennfolk-reed-boats.webp
    half-v-druid-trio.webp
    column-robin-fox-mask.png
    ink-fimir-brood-mother.png
    spot-wolf-head.png
    heraldry-blue-host.png
    texture-parchment.webp

PNG with alpha for cutouts, heraldry and ink work. WEBP for large painted pieces,
with the original archived elsewhere.

Each file wants a sibling `.md` carrying its subject, intended editorial use, pixel
dimensions, whether it is painted or monochrome ink, and the creator's approval date.
