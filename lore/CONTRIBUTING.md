# Albion lore contribution workflow

This branch is a **draft workspace**. Changes here are not approval for publication.

1. Add one Markdown file per fictional subject under the relevant lore category.
2. Identify confirmed information, developing ideas, and unanswered questions separately.
3. Never invent facts to fill gaps. Never import raw chat transcripts or personal biographical information.
4. Keep artwork and layout independent of the canon entry.
5. Have the project owner explicitly approve individual entries before they are merged into the public site or into `main`.
6. Preserve references and connections to related fictional entries.

The book is a 1920×1080 two-page spread with **two text columns per page**; these presentation rules belong to the website, not the lore files.
