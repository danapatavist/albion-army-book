# Albion canon library — draft

This is a structured library of fictional Albion lore. It is **not** a record of the creators' conversations, and must never contain personal information, private experiences, or identifying details about real people.

## Rules

- `status: draft` means **not approved for publication**.
- Keep confirmed lore separate from proposals and unresolved questions.
- Do not invent characters, dates, relationships, locations, rules, or statistics to complete a page.
- Treat content already present in the demo website as unverified until checked against canon.
- Never merge this material into `main` or publish it without explicit approval.
- Use one Markdown file per subject, with clear cross-reference names.
- No AI should infer a creator's biography from fictional lore.

## Proposed categories

- `characters/`
- `hosts/`
- `creatures/`
- `places/`
- `history/`
- `cultures/`
- `magic/`
- `artefacts/`
- `units/`

## Website layout contract

The book uses a 1920 × 1080 two-page spread. Each *individual* page defaults to two text columns, for four columns across a spread. Content files should not contain page-layout HTML: the website chooses how to present them.
