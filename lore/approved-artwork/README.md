# Approved artwork

Artwork the creator has approved for use in the book. `codex-layout.json` references
files here by name; anything still being iterated on belongs outside this folder.

Name files by format and subject, lowercase kebab-case, per the editorial spec:
`spread-wild-hunt-barrows.webp`, `page-alfran-on-shaggy.webp`,
`half-h-fennfolk-reed-boats.webp`, `column-fox-mask.png`, `ink-fimir-brood-mother.png`.

PNG with alpha for cutouts, heraldry and ink work; WEBP for large painted pieces.

A referenced file that is not here is not an error. The build marks it missing and the
page prints a holding box naming the file it wants, so a layout can be art-directed
before the art exists.
